# Contextual canvas

[Catalogue](readme.md)

## Condition

For Composition, CallChain and DataModel, the canvas encloses the initialized project containers. Retain any additional extent reserved by the initial route builder; this rule only grows an insufficient canvas.

## Verification

Test an unmet condition, its adjustment or diagnostic, and an unchanged second application. Test applicability separately from other diagram types.

## Implementation

[ContextualCanvasLayoutRuleProcessingService](../../StandardIo.ArchitectureDiagram.Core2/Services/Processings/Layout/ContextualCanvasLayoutRuleProcessingService.cs)

## Applicability

Composition, CallChain and DataModel.

## Allowed changes

Canvas width and height only; never shrink route-builder extents.
